ResiLens AI is an intelligent AI-powered resume screening and recruitment assistance platform designed to simplify and enhance the hiring process. The project uses Machine Learning and Natural Language Processing techniques to analyze resumes, compare them with job descriptions, and classify candidates into categories such as Shortlisted, Needs Review, or Rejected based on their suitability for the role.

The platform provides features like resume upload and analysis, AI-generated recruiter feedback, candidate history tracking, PDF resume preview, skill matching, and an AI chatbot assistant for recruiter support. The system is built using a modern full-stack architecture with Next.js and Tailwind CSS for the frontend, FastAPI for the backend, MongoDB for database management, and Scikit-learn for implementing the machine learning model.

ResiLens AI aims to reduce manual screening effort, improve recruitment efficiency, and provide intelligent insights to recruiters using AI-driven automation and predictive analysis.
